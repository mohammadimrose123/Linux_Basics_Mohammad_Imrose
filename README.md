## Objective

This project demonstrates essential Linux command-line operations including:

- File and directory management
- Viewing file contents
- Searching for patterns
- Zipping and unzipping files
- Downloading files using wget
- Changing file permissions
- Working with environment variables

## Tasks Completed

### 1. Creating and Renaming Files/Directories

Created `test_dir`, created `example.txt`, and renamed it to `renamed_example.txt`.

### 2. Viewing File Contents

Used `cat`, `head`, and `tail` to view `/etc/passwd`.

### 3. Searching for Patterns

Used `grep` to search for lines containing `root`.

### 4. Zipping and Unzipping

Compressed `test_dir` into `test_dir.zip` and extracted it into `unzipped_dir`.

### 5. Downloading Files

Used `wget` to download a sample file.

### 6. Changing Permissions

Created `secure.txt` and changed its permissions to read-only using `chmod 444`.

### 7. Environment Variables

Created the environment variable `MY_VAR` with the value `Hello, Linux!`.
